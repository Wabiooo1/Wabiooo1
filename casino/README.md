Casino Gold - versión visual mejorada (v3)
=========================================

Qué hay de nuevo:
- Interfaz y estilo mejorados para Buscaminas y Blackjack.
- Animaciones CSS y pequeñas animaciones JS (reparto/clicks).
- Mejor layout responsive y panel lateral con controles.
- Música de ambiente incluida (static/audio/ambient.wav).
- SVGs decorativos para gemas, bombas y fichas.

Ejecutar:
1. python -m venv venv
2. source venv/bin/activate  (Windows: venv\Scripts\activate)
3. pip install -r requirements.txt
4. python app.py

Notas:
- RNG sigue siendo client-side.
- Si quieres assets fotorealistas, puedo reemplazar los SVGs por PNGs libres de derechos.
